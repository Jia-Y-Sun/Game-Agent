1. 项目概述
────────────────────────────────────────────────────────────────────────────

  Python自动化脚本，用于金铲铲之战游戏的自动对局操作。
  通过图片识别(OpenCV模板匹配)和OCR文字识别(easyocr)实现游戏状态检测，
  模拟鼠标点击和拖拽完成自动操作。

  运行环境：
    - Python 3.x
    - 分辨率: 2560x1600 (支持其他分辨率，坐标自动缩放)
    - 模拟器: 雷电模拟器 / LDPlayer

4. 核心模块说明
────────────────────────────────────────────────────────────────────────────

  4.1 image_recognition.py - 图片识别
  ────────────────────────────────────────────────────────────────────────────
    基于OpenCV模板匹配:

    find_image(template_path, region, confidence)
      -> 返回中心坐标(x, y)或None
      多尺度匹配: [0.4, 0.6, 0.8, 1.0] 自动缩放

    click_image(template_path, timeout, confidence)
      -> 等待图片出现并点击，返回True/False

    find_question_mark_superfast()
      -> 专用问号检测(限定区域+2种模板)

    wait_for_image(template_path, timeout, confidence)
      -> 轮询等待图片出现

  4.2 ocr_helper.py - OCR文字识别
  ────────────────────────────────────────────────────────────────────────────
    基于easyocr (ch_sim + en 模型):

    启动时后台线程初始化，不阻塞主流程。

    ocr_text(image) -> 返回识别文本
    read_round_number(image) -> 识别"1-1""2-4"等轮数格式
    read_countdown(image) -> 识别"00:30"等倒计时格式

  4.3 phase_detector.py - 阶段检测
  ────────────────────────────────────────────────────────────────────────────
    基于OCR识别以下信息(区域为屏幕顶部4cm):

    OCR区域(基准2560x1600):
      ROUND_REGION       = (0, 0, 800, 150)        顶部左侧
      COUNTDOWN_REGION   = (1000, 0, 1560, 150)    顶部右侧
      PHASE_REGION       = (0, 0, 2560, 150)       整个顶部

    detect_round()         -> 返回"1-1""2-4"等
    detect_countdown()     -> 返回"00:30"等
    detect_prepare_phase() -> 返回True/False(检测"准备阶段")
    detect_battle_phase()  -> 返回True/False(检测"战斗开始")
    is_carousel_round(r)   -> 判断是否为选秀轮(x-4)

    降级策略:
      若OCR 5秒内检测不到"准备阶段"，自动使用固定30秒周期

  4.4 mouse_controller.py - 鼠标操作
  ────────────────────────────────────────────────────────────────────────────
    基于pyautogui:

    click(x, y, delay)      - 点击坐标
    double_click(x, y)      - 双击
    drag(x1, y1, x2, y2)     - 拖拽
    move_to(x, y)           - 移动鼠标
    scroll(amount)          - 滚动

  4.5 game_state.py - 游戏状态
  ────────────────────────────────────────────────────────────────────────────
    GameState类管理:
      - 备战区/战斗区棋子状态
      - 金币数量
      - 准备阶段剩余时间

  4.6 game_flow.py - 游戏流程
  ────────────────────────────────────────────────────────────────────────────
    GameFlow类: 主控制器

6. 坐标缩放机制
────────────────────────────────────────────────────────────────────────────

  所有坐标在config.py中以1920x1080为基准定义，
  运行时自动缩放到当前实际分辨率:

    def _scale_coords(x, y):
        sw, sh = pyautogui.size()
        return (int(x * sw / 1920), int(y * sh / 1080))

  例如 2560x1600 下，缩放因子:
    x: 2560/1920 = 1.33
    y: 1600/1080 = 1.48

  OCR区域同样缩放(以2560x1600为基准):
    def _scale_region(reg):
        sw, sh = pyautogui.size()
        return (int(reg[0]*sw/2560), int(reg[1]*sh/1600),
                int(reg[2]*sw/2560), int(reg[3]*sh/1600))

8. 关键参数
────────────────────────────────────────────────────────────────────────────

  PAGE_LOAD_DELAY    = 1.5s   页面加载等待
  MATCH_FOUND_DELAY  = 0.5s   匹配成功等待

  准备阶段时间分配:
    购买英雄:  5秒 (每秒点1次最右位置)
    购买经验:  10秒 (点击5次)
    上场英雄:  5秒 (拖拽)
    丢弃英雄:  7秒 (拖拽+停留2秒)

  ? 圆圈守护线程:
    检测间隔: 0.5秒
    点击后休眠: 1.0秒

  PLUS守护线程:(已合并入?守护进程)
    检测间隔: 0.3秒
    置信度: 0.7

  拖动偏移量:
    上场起点: 右侧偏移190px + 上移90px
    上场终点: 战斗区 + 上移90px
    丢弃起点: 同上场起点
    丢弃终点: 起点向下150px (约4cm)
    丢弃停留: 2秒 (不松开鼠标)


9. 已知限制
────────────────────────────────────────────────────────────────────────────

  - OCR首次启动需下载模型文件(约100MB)，后台下载不阻塞启动
  - 坐标基于雷电模拟器2560x1600窗口，其他分辨率需要验证
  - 图片识别依赖屏幕截图质量，缩放比例不合适时可能匹配失败
  - 拖动操作不保证模拟器精确响应
