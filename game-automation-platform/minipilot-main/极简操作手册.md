# 极简操作手册

以下步骤用于完成一次 MiniPilot 集成采集。首次部署前请先按[安卓端侧 APP 样本采集方案](安卓端侧APP样本采集方案.md)完成电脑、手机、模型和 PCAPdroid 配置。

## 一、首次安装

1. 在终端进入项目根目录。
2. 创建虚拟环境：

   ```bash
   python -m venv .venv
   ```

3. 激活虚拟环境并安装依赖。

   Windows PowerShell：

   ```powershell
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   Copy-Item mini_pilot.config.example.json mini_pilot.config.json
   ```

   macOS/Linux：

   ```bash
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   cp mini_pilot.config.example.json mini_pilot.config.json
   ```

4. 安装并启用 ADBKeyboard：

   ```text
   adb install -r ADBKeyboard.apk
   adb shell ime enable com.android.adbkeyboard/.AdbIME
   adb shell settings get secure default_input_method
   adb shell ime set com.android.adbkeyboard/.AdbIME
   adb shell settings get secure default_input_method
   adb shell ime list -s
   ```

   记录第一次查询返回的原输入法。切换后查询和输入法列表必须显示 `com.android.adbkeyboard/.AdbIME`。AutoGLM、Seed LLM Agent 执行文本输入时依赖它。

5. 将项目配套的定制 PCAPdroid APK 放在项目根目录，然后将占位文件名替换为实际名称并安装：

   ```text
   adb install -r <定制PCAPdroid文件名>.apk
   adb shell pm list packages com.emanuelef.remote_capture
   ```

   检查命令必须显示 `com.emanuelef.remote_capture` 或 `com.emanuelef.remote_capture.debug`。

6. 打开 PCAPdroid 的 `Settings > Control Permissions`，生成并复制 API Key。

7. 编辑 `mini_pilot.config.json`：
   - 使用 AutoGLM：登录[智谱开放平台](https://open.bigmodel.cn/)，在 [API Keys](https://open.bigmodel.cn/usercenter/proj-mgmt/apikeys) 页面创建 Key，将 `executor.active_profile` 设为 `autoglm`，并将 `YOUR_ZHIPU_API_KEY` 替换为该 Key。保持 `base_url` 为 `https://open.bigmodel.cn/api/paas/v4`、`model` 为 `autoglm-phone`。
   - 使用 Seed 2.0 Pro：登录火山方舟，在[API Key 管理](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey)页面创建 Key，将 `executor.active_profile` 设为 `seed2pro`，并将 `YOUR_ARK_API_KEY` 替换为该 Key。保持 `base_url` 为 `https://ark.cn-beijing.volces.com/api/v3`、`model` 为 `doubao-seed-2-0-pro-260215`；若方舟控制台显示的可调用模型 ID 已更新，以控制台为准。
   - 后处理 VLM 必填：登录[阿里云百炼](https://bailian.console.aliyun.com/)，在华北 2（北京）的“API Key”页面创建 Key，将 `YOUR_DASHSCOPE_API_KEY` 替换为该 Key。当前 `postprocess_vlm_base_url` 填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，`postprocess_vlm_model` 填 `qwen-vl-plus`。如果新建 Key 弹窗给出了包含业务空间 ID 的 API Host，则以弹窗地址替换 `postprocess_vlm_base_url`。Key、API Host 和业务空间必须一致。
   - 将 `capture.pcapdroid_api_key` 的 `YOUR_PCAPDROID_API_KEY` 替换为手机端 PCAPdroid 生成的 Key。字段名是单数 `pcapdroid_api_key`，不要写成 `pcapdroid_api_keys`。该 Key 与上述两个模型平台的 Key 无关。

8. 验证所选模型，看到 `SUCCESS` 后再继续：

   ```bash
   python model_ping.py --target autoglm
   ```

   使用 Seed 2.0 Pro 时改为 `python model_ping.py --target seed2pro`。

   再验证 Qwen-VL：

   ```bash
   python model_ping.py --target postprocess_vlm
   ```

## 二、每次采集前

1. 激活 `.venv`。
2. 在手机“开发者选项”中确认：
   - “USB 调试”已开启。
   - 如果手机提供“USB 调试（安全设置）”和“通过 USB 安装”，两项均已开启。
   - “保持唤醒/不锁定屏幕”已开启。
3. 关闭省电模式；将目标 APP 和 PCAPdroid 的电池策略设为“不限制”。把自动锁屏和锁屏后自动上锁时间调到最长。
4. 使用支持数据传输的 USB 线连接手机，选择“文件传输”模式并保持手机解锁。
5. 首次连接时，在手机 RSA 授权弹窗中勾选“始终允许”，然后允许。
6. 重新启动 ADB 服务并确认连接：

   ```text
   adb kill-server
   adb start-server
   adb devices -l
   ```

   设备状态必须是 `device`。如果显示 `unauthorized`，解锁手机并接受授权；显示 `offline` 时重新插拔数据线后再执行以上命令。
   如果同时连接多台设备，后续每条手工 ADB 命令都要写成 `adb -s <设备序列号> ...`。
7. 在手机界面中记录任务前的“自动熄屏”“锁屏后自动上锁”“保持唤醒”和电池策略。
8. 通过手机设置界面配置长时间运行：
   - “设置 > 显示与亮度 > 自动锁屏/休眠”选择“永不”；没有“永不”时选择最长时间。
   - “设置 > 密码与安全/锁屏 > 锁屏后自动上锁”选择最长时间。
   - “开发者选项 > 保持唤醒/不锁定屏幕”设为开启。
   - “设置 > 电池”关闭省电和超级省电，将目标 APP、PCAPdroid 的电池策略设为“不限制”。
   - 在最近任务界面锁定目标 APP 和 PCAPdroid（如果手机支持）。
   - 保持手机接入电源，点亮并人工解锁屏幕。
9. 将 ADBKeyboard 手动设为默认输入法并验证：

   ```text
   adb shell ime enable com.android.adbkeyboard/.AdbIME
   adb shell ime set com.android.adbkeyboard/.AdbIME
   adb shell settings get secure default_input_method
   adb shell ime list -s
   ```

   查询结果必须包含 `com.android.adbkeyboard/.AdbIME`。
10. 确认目标 APP 已安装、已登录。
11. 无 Root 抓包时，确认安装的是项目配套的定制 PCAPdroid、VPN 权限有效且 API Key 没有变化。
12. 检查 MiniPilot 设备状态：

   ```bash
   python -m mini_pilot.main --check-device
   ```

13. 检查模型：

   ```bash
   python model_ping.py --target autoglm
   ```

   使用 Seed 2.0 Pro 时改为 `python model_ping.py --target seed2pro`。

   然后执行 `python model_ping.py --target postprocess_vlm` 检查 Qwen-VL。

14. 任务超过 180 秒时，确认 scrcpy 可用：

   ```bash
   scrcpy --version
   ```

## 三、使用 GUI 自动采集

1. 启动 GUI：

   ```bash
   python -m mini_pilot.gui
   ```

2. 在 `Device` 选择目标手机。
3. 在 `Goal` 输入要完成的业务目标。
4. 在 `Duration` 输入有效业务时长，单位为秒，例如 `300`。
5. `Capture` 选择 `unicapture`。
6. 依次选择 Category、App 和 Scene。
7. 点击 `Start`。
8. 保持手机连接、解锁，不要启动其他 ADB 或抓包任务。
9. 运行中需要调整时，在 Live Command 输入内容：
   - `Send`：替换当前持续任务要求。
   - `Once`：只执行一次。
   - `Clear`：清空实时补充要求。
   - `Stop`：停止任务并收集文件。
10. 等待主日志出现 `TASK_STATUS: SUCCESS`，并记下显示的 Run dir。

## 四、使用命令行自动采集

将设备序列号、APP 和场景替换为本次实际值：

```text
python -m mini_pilot.main --goal "打开抖音，浏览推荐短视频 5 分钟" --run-duration 300 --capture unicapture --capture-app douyin --capture-scene feed --device-id YOUR_ADB_DEVICE_SERIAL
```

如果只连接一台状态为 `device` 的手机，可以省略 `--device-id`。

## 五、人工操作并自动采集

1. 执行：

   ```text
   python -m mini_pilot.main --manual --goal "人工操作抖音推荐流 5 分钟" --run-duration 300 --capture unicapture --capture-app douyin --capture-scene feed --device-id YOUR_ADB_DEVICE_SERIAL
   ```

2. 等待终端显示 Unicapture 已就绪。
3. 直接在手机上完成目标业务操作。
4. 等待有效业务倒计时结束；需要提前结束时按 `Ctrl+C`。
5. 不要在文件收集和后处理完成前拔掉数据线。

## 六、重复采集

```text
python -m mini_pilot.main --goal "打开快手浏览推荐流 3 分钟" --run-duration 180 --capture unicapture --capture-app kuaishou --capture-scene feed --repeat-count 5 --repeat-delay 10
```

每轮完成后等待 10 秒，并创建新的运行目录。

## 七、检查结果

1. 打开终端显示的 `runs/<本次运行>/`。
2. 检查 `execution/summary.json` 中的 `success`。
3. 打开 `capture/` 下的样本目录。
4. 确认需要的文件存在：
   - `cut_*.pcap` 或 `cut_*.pcapng`
   - `*.mp4`
   - `*.log`
   - `*.yaml`
   - `*_sa.csv`
   - `*_qoe.csv`
5. 检查 `postprocess/summary.json`：
   - `status: ok`：业务时间和 QoE 后处理均成功。
   - `status: partial_error`：打开其中的 `activate_time` 和 `qoe` 查看失败原因；原始采集文件仍然保留。
6. 发生问题时查看 `capture/unicapture_stdout.log`。

## 八、常用替代命令

不抓取网络流量：

```bash
python -m mini_pilot.main --goal "测试任务" --capture unicapture --capture-no-pcap
```

不执行后处理：

```bash
python -m mini_pilot.main --goal "测试任务" --capture unicapture --capture-disable-postprocess
```

只运行 Agent，不采集：

```bash
python -m mini_pilot.main --goal "打开设置" --capture none
```

查看已连接设备：

```bash
python -m mini_pilot.main --list-devices
```

查看内置采集 APP 及每个 APP 可用的场景名：

```bash
python -m mini_pilot.main --list-apps
```

查看指定 APP 的场景说明和默认采集时长：

```bash
python -m mini_pilot.main --list-scenes douyin
```

生成发布包：

```bash
python package_project.py
```

## 九、任务结束后恢复手机设置

1. 等待样本文件收集和后处理完成后再断开手机。
2. 在手机设置界面按任务前记录恢复自动熄屏、锁屏后自动上锁、“保持唤醒”、省电模式和应用电池策略。
3. 如需恢复原输入法，保留使用 ADB 输入法命令：

   ```text
   adb shell ime set <任务前记录的原输入法ID>
   adb shell settings get secure default_input_method
   ```
