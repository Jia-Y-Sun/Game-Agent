# 样本输出文件格式说明

本说明描述一次完整采集后生成的 6 种标准文件及其格式。

## 文件命名规范

```
{应用名}_{设备ID}_{场景}_{分辨率}_{时长}_{时间戳}

示例：mango_b29154b4_movie_liuchang360P_10_20260318T221434
```

## 1. 流量报文（PCAP）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `cut_mango_b29154b4_movie_liuchang360P_10_20260318T221434.pcap` |
| 文件名格式 | `{应用行为}_{手机编号}_{场景}_{分辨率}_{时长}_{采集时间}.pcap` |
| 采集方式 | root 模式使用 `tcpdump`；无 root 模式使用 PCAPdroid 等 VpnService App |
| 内容 | 目标业务期间的完整网络报文 |
| 备注 | 示例文件可只截取前 N 个报文以控制大小 |

## 2. 环境信息（YAML）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `mango_b29154b4_movie_liuchang360P_10_20260318T221434.yaml` |
| 内容 | 采集环境、设备信息、操作记录 |

主要字段：

| 字段 | 含义 |
|------|------|
| `task_info` | 手机操作记录 |
| `phone_info` | 手机品牌、型号、OS 版本 |
| `app_info` | 拨测应用、任务类型、板块等信息 |
| `qoe_info` | QoE 业务触发的起始时间 |
| `packet_capture` | pcap 信息，需重点记录用户 IPv4/IPv6 |
| `video_record` | 录屏文件的开始和结束时间 |

## 3. SA 流标注（CSV）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `mango_b29154b4_movie_liuchang360P_10_20260318T221434_sa.csv` |
| 内容 | 每条流的 SA 标注信息 |

必要列：

| 列名 | 说明 |
|------|------|
| pcap 名字 | 对应 pcap 文件名 |
| 拨测应用大类 | 应用类型，如 video、game、social |
| 拨测应用名字 | 具体应用名，如 mango、honorofkings |
| srcip | 源 IP |
| dstip | 目的 IP |
| srcport | 源端口 |
| dstport | 目的端口 |
| l4proto | 传输层协议 |
| not_in_app | 是否是业务流 |
| egn_sub_protocol | 标注结果/应用层协议识别结果 |

## 4. QoE 关键指标（CSV）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `mango_b29154b4_movie_liuchang360P_10_20260318T221434_qoe.csv` |
| 内容 | 目标业务开始后每秒的 QoE 关键指标 |

字段说明：

| 字段 | 说明 |
|------|------|
| `file_name` | pcap 文件名 |
| `time` | 时间戳（每秒一条） |
| `trust_stall` | 卡顿状态。0=不卡，1=卡顿，<0=目标业务未开始 |
| `trust_resolution` | 分辨率。具体数值或 <0=目标业务未开始 |
| `rtt` | 往返时延（ms），仅手游。>0=正常，<0=目标业务未开始 |

## 5. 屏幕录屏（MP4）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `mango_b29154b4_movie_liuchang360P_10_20260318T221434.mp4` |
| 内容 | 从采集流量开始时同步录制的屏幕视频 |
| 要求 | 录屏需包含完整业务行为 |
| 备注 | 示例文件可只保留前 1 分钟以控制大小 |

## 6. 系统日志（LOG）

| 项目 | 说明 |
|------|------|
| 文件名示例 | `mango_b29154b4_movie_liuchang360P_10_20260318T221434.log` |
| 内容 | 采集期间的 `adb logcat` 日志 |
| 权限 | 完整获取需要 READ_LOGS 权限或 root 权限 |
| 备注 | 若权限不足，该文件可能为空或缺失 |

## 生成方式

执行主采集脚本即可自动生成上述文件：

```bash
python app_collector.py --app-name mango --scene movie --duration 600
```
